Behavior notes

  • Profile pill: always ✓ (user can't reach /panel without it)
  • Category pill: green when user has ≥1 category; links to /panel/categories
  • Dishes pill: green when user has ≥1 dish; links to /panel/onboarding/dishes (new photo import hero page)
  • Share QR pill: always last; links to /panel scrolled to QR section
  • Dismiss ×: hides banner via localStorage flag (not permanent — reappears if they clear storage)
  • Completion check runs server-side — no flicker. Counts fetched alongside existing restaurant data.
